# Credits — Oakcrown (slug `chess-checkers`)

## Name check (2026-10-28)
- Working title **"Rookery"**: rejected. Web search found *The Rookery*, a released chess roguelite on Steam (Glyder Games, 2024), plus "Rookery Interactive" game-studio trademark filings. In the same product category, so too close to use.
- Replacement **"Oakcrown"**: web searches for "Oakcrown" game / chess / checkers / app (2026-10-28, re-checked 21:20 PT) found no game, app or game-related trademark. The only hits were unrelated UK companies: Oakcrown Developments Ltd (property), Oakcrown Ltd and Oakcrown Computers Ltd (a VAT listing). These are not in games or entertainment software. This is not a legal clearance; a formal trademark search is recommended before heavy marketing.

## Code
- Everything in this folder except `hexan.js` was written from scratch for Playtoom:
  - rules: `chess.js` (0x88 board, Zobrist hashing) and `checkers.js`;
  - AI: `chess-ai.js` (PVS, iterative deepening, aspiration windows, transposition table, quiescence, null move, LMR, futility pruning, original hand-written evaluation and formula-based piece-square tables) and the checkers search in `checkers.js`;
  - worker glue (`worker.js`), the puzzle generator and prover (`tools/gen-puzzles.js`), art (`art.js`), social features (`social.js`) and the game itself (`game.js`).
- No engine, opening book, endgame table, evaluation weights or puzzle set was copied from any other project. The perft reference numbers in `tools/rules-test.js` are public test values; they are used only to check our move generators.
- Engine: Hexan Engine 1.2.1 (`hexan.js`), original, copied unmodified.

## Puzzles
- All chess and checkers puzzles were generated by our own engine from computer self-play (`tools/gen-puzzles.js`). None are taken from any database.
- **Chess:** each puzzle is proven by exhaustive search to be a checkmate in N (1–3) with exactly one winning first move and no faster mate. The defender's replies are the most stubborn ones, and each attacking move in the line is unique.
- **Checkers:** each puzzle's key moves beat every alternative by at least 1.1 men, by depth-8 search.

## Art
- Drawn procedurally on canvas at runtime: the original carved-wood and brass piece designs, the five board themes and the felt table. There are no image files.
- The thumbnails in `thumbs/` were rendered from the game itself.

## Sound and music
- Synthesized at runtime with WebAudio (`HX.Audio`): the wooden piece clacks, capture thumps, chimes and the original parlour waltz. There are no sample files.
