# Credits: Thrumdash

- Game design, code and levels: original, written for FizzSoup on Hexan Engine 1.2.1 (`hexan.js`, unmodified).
- Music: composed at runtime from each level's seed (`music.js`): scales, chord progressions, motifs, bass lines and drum patterns are generated by code and synthesized with WebAudio oscillators and noise. No samples, no recordings, no third-party melodies.
- Sound effects: Hexan `HX.Audio` presets plus Thrumdash synth voices. No sample files.
- Art: neon ink-on-black paper-cut style drawn procedurally on canvas at runtime (`art.js`). No image files except the generated store thumbnails.
- Level generator and rhythm timing: original (`core.js`). Every level is verified solvable by the generator and by `qa/solver.js`.
- Fonts: platform brand fonts Nunito and Fredoka (Latin WOFF2 subsets, SIL Open Font License 1.1), bundled locally by the engine build into `brand/fonts/` with their licence texts; system UI fallback. Nothing is downloaded from outside.
- Name: "Thrumdash" was checked against web search on 2026-10-28; no game or trademark with that name was found.
- Genre note: one-touch rhythm runners are a broad genre. Thrumdash uses no names, assets, levels, icons or music from any other game.
- Third-party assets: none.
