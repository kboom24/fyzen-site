# Credits — Gem Lattice

- Game design, code and the "Gem Lattice" name and logo are original work for Hexan. The name was checked against web search on 26 Oct 2026 (PT). It does not match an existing game; "Gridlock Gem Blast" is an existing slot game, so the working title was dropped. A formal trademark search is still needed before launch.
- Engine: Hexan Engine (`hexan.js`), original.
- Art: all gems, the board, the background lattice, bokeh, the logo emblem and the wordmark are drawn procedurally with Canvas 2D at runtime. No image files.
- Sound and music: synthesized at runtime with WebAudio (`HX.Audio` presets plus an original 32-step ambient loop). No sample files.
- Fonts: FizzSoup brand fonts Nunito (© 2014 The Nunito Project Authors) and Fredoka (© 2016 The Fredoka Project Authors), SIL Open Font License 1.1, bundled locally as Latin WOFF2 subsets in `brand/fonts/` with their licence texts; system UI fallback. Nothing is downloaded from outside.
- Genre note: block placement on a grid is a common, unprotected game mechanic. No names, art, sounds, UI layouts or level data were taken from any existing game.
- Third-party assets: the OFL fonts above. Platform brand artwork (splash, badge, favicons) is the FizzSoup brand kit.
