# Credits — Sizzle & Mizzle

- Game design, levels, code: original, written for Hexan / FizzSoup by FizzSoup Game Builder 13. Engine: Hexan Engine 1.2.1 (`hexan.js`), original, used unmodified.
- Characters (Sizzle, Mizzle), level layouts (40 levels in 4 chapters) and story text: original. Only the general co-op elemental puzzle-platformer mechanic is shared with the genre.
- Art: drawn procedurally on canvas at runtime (stained-glass temple backdrops, rose windows, tiles, heroes, UI). No image files.
- Sound and music: synthesized at runtime with WebAudio (`HX.Audio` tone + step sequencer, `audio.js`). No sample files.
- Fonts: platform brand fonts Nunito and Fredoka (Latin WOFF2 subsets, SIL Open Font License 1.1), bundled locally by the engine build into `brand/fonts/` with their licence texts; system UI fallback. Nothing is downloaded from outside.
- Third-party assets: none.
- Name check: "Sizzle & Mizzle" was chosen after a web search (2026-10-29) found no game, app or trademark using it ("Ember & Brook" was rejected as an existing brand). This was a web search only, not a formal trademark clearance.
